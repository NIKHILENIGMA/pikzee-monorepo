# @pikzee/editor (Future Package)

Path: `libs/documents`

## Purpose

Encapsulates all **TipTap editor configurations, style overrides, and custom React NodeViews** to provide a Notion-style, premium block editor.

---

## Planned Modules

- **`<TiptapEditor />` Component:** React component exposing standard attributes like content, collaboration tokens, and events.
- **Custom Node Views:** Rich React views for Callouts, Code Blocks with syntax highlight, and Image Upload blocks.
- **Slash Command (`/`):** Command triggers mapping keyboard keystrokes to block elements insertions.
