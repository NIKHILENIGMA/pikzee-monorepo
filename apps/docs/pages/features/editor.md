# 📝 Rich Text Editor

The Pikzee rich-text editor is built on top of the TipTap framework, providing a highly customizable, block-based, collaborative writing canvas.

---

## 1. Document Canvas Structure

- **[Core Setup](/features/editor/tiptap):** Configures standard ProseMirror extensions and binds default nodes to our Tailwind CSS v4 class tokens.
- **[Custom Extensions](/features/editor/extensions):** Adds premium Notion-like features including Slash (`/`) commands, bubble menus, code blocks, and Warning/Info callout boxes.
