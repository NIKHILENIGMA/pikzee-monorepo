# 2026-07-04 — Documentation Portal Setup

**Session focus:** Bootstrap the internal documentation portal at `apps/docs`.

## What was done

- ✅ Decided on `apps/docs` as a proper Nx-managed application (not a standalone scaffold)
- ✅ Generated `apps/docs` using `nx generate @nx/react:application` with Vite + SWC
- ✅ Added Zudoku as the documentation layer on top of the Nx React+Vite app
- ✅ Wired Zudoku's Vite plugin into `vite.config.mts`
- ✅ Created `zudoku.config.ts` with 9 navigation domains
- ✅ Seeded initial content for all domains:
  - Getting Started (setup, commands, project structure)
  - Frontend (auth, routing, components)
  - Backend (modules, auth, database)
  - Infrastructure (Docker, Redis, PostgreSQL, CI)
  - Packages (shared-types, shared-ui, shared-config, shared-utils)
  - Collaboration (Yjs, Hocuspocus, presence, asset feed)
  - Decisions (D-01, D-02, D-03 from TODO.md)
  - Dev Log (this entry)
- ✅ Migrated root `DEVLOG.md` to point here
- ✅ Created `public/diagrams/` folder for future PNG diagram embeds from Eraser

## Decisions made

- 💡 **Nx generator over standalone Zudoku scaffold** — gives full Nx graph integration, caching, and `nx run docs:dev` out of the box
- 💡 **Standalone Zudoku app** — cleaner separation than embedding in `apps/web`, can be deployed independently
- 💡 **PNG exports for architecture diagrams** — Eraser diagrams will be exported as PNG and placed in `public/diagrams/`
